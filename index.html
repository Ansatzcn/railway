编辑条目

可修改车次，并为该车次增加或移除多个车站。

每次输入或选择一个车站，然后按回车或点击“加入”。

管理车站

可修改或删除下拉菜单中的历史车站。修改名称时可同步更新现有条目；删除只移除候选项，不删除车次记录。

候选项会继续按拼音首字母排序。删除后的名称若再次用于新增或编辑条目，会重新进入候选列表。

GitHub 云端配置
